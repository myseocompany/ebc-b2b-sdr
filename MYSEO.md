# MYSEO

## Qué es este repositorio

Es el entorno operativo de MySEO para diseñar, ejecutar y verificar intervenciones de marketing y arquitectura de ingresos asistidas por LLM.

## Método base

`SCAN → CONFIGURE → INSTALL → LAUNCH → MONITOR`

- **SCAN:** comprender negocio, datos, recorrido, línea base y restricciones.
- **CONFIGURE:** formular hipótesis, métricas, segmentos, canales y responsabilidades.
- **INSTALL:** preparar CRM, tracking, mensajes, activos, automatizaciones y controles.
- **LAUNCH:** activar pruebas controladas después de la aprobación humana.
- **MONITOR:** conciliar evidencia, aprender y decidir si escalar, ajustar o detener.

## Arquitectura de ingresos

- **Adquisición:** clientes nuevos y su ingreso inicial.
- **Retención:** base que permanece y valor que se protege.
- **Expansión:** valor adicional generado por clientes existentes.

La retención no se suma como ingreso incremental sin definir primero la base en riesgo. La expansión no se confunde con adquisición.

## Métricas universales

- Volumen: cuántos entran o están disponibles en cada etapa.
- Conversión: qué porcentaje avanza a la siguiente etapa.
- Tiempo: cuánto tarda el avance.
- Valor: ingreso neto, margen o valor protegido, cuando exista fuente confiable.
