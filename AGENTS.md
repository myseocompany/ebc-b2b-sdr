# AGENTS

Punto de entrada para cualquier LLM que opere en el repositorio **EBC — B2B SDR**.

Cliente único de este repositorio: **Eléctricas BC Corp (EBC)**. Contrato vigente en `PROPUESTA.md`.

Antes de actuar, leer en este orden:

1. `SOUL.md` — rol y principios.
2. `MYSEO.md` — organización, método y objetivos.
3. `POLICIES.md` — límites y aprobaciones.
4. `PROPUESTA.md` — contrato vigente (olas, SLA, honorarios, condiciones de salida).
5. `MEMORY.md` — índice de conocimiento persistente.
6. `SOURCES.md` — jerarquía de fuentes.
7. `TASKS.md` — trabajo actual.
8. `DECISIONS.md` — decisiones vigentes.
9. `README.md` — mapa del repositorio.

## Reglas de operación

- Identificar el objetivo antes de trabajar. Si no está claro, preguntar antes de actuar.
- Cargar detalles bajo demanda; no leer todo el repositorio por defecto.
- Separar hechos, inferencias, propuestas y decisiones aprobadas.
- Separar adquisición, retención y expansión. No llamar “palanca” indistintamente a segmentos, canales, etapas o métricas.
- En adquisición, separar siempre `origen del lead` de `segmento del lead`.
- No presentar clics, conversaciones, solicitudes o documentos como ventas o conversiones finales.
- Antes de una acción externa, verificar `POLICIES.md` y el workflow aplicable.
- Publicar, enviar campañas, modificar presupuestos, borrar datos, aprobar ofertas o tocar producción requiere autorización humana explícita.
- Las credenciales nunca se leen, copian ni exponen. Usar solo mecanismos seguros ya configurados.
- Mantener `TASKS.md` y `progress/` actualizados en tareas largas.
- Una tarea termina por evidencia y criterios verificables, no porque el LLM declare que terminó.
- Todo aprendizaje permanente debe tener fuente, fecha y utilidad futura antes de entrar en `MEMORY.md`.

## Flujo mínimo

`entender → localizar fuentes → proponer/planear → ejecutar dentro del alcance → verificar → documentar evidencia → actualizar estado`

Consultar el archivo correspondiente en `workflows/` antes de investigar, diseñar campañas, preparar lanzamientos, monitorear o reportar.
